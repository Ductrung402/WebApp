# AGENTIC CONTRACT: QUIZ AI & EXAM SYSTEM
**Project Scope:** 5-week Web Programming Project (Independent Developer)
**Tech Stack:** ReactJS, FastAPI, PostgreSQL, Socket.io, Gemini API
**Target Engine:** Cursor AI / LLM Coding Assistants

## I. MODULE BOUNDARIES & RESPONSIBILITIES (WHAT TO BUILD)

### 1. Database Module (PostgreSQL + SQLAlchemy)
- **Single Source of Truth:** `models.py`. Tuyệt đối không thay đổi schema (không thêm cột, bảng, hoặc đổi tên) nếu không có lệnh trực tiếp từ Developer.
- **Naming Convention:** Bắt buộc dùng `snake_case` cho Database/Model và `camelCase`/`PascalCase` cho Frontend/Pydantic schemas.
- **Data Integrity:** Lệnh `cascade="all, delete-orphan"` phải được áp dụng nghiêm ngặt tại các mối quan hệ cấu thành (Composition): Xóa `DeThi` -> Xóa sạch `CauHoi`; Xóa `PhongThi` -> Xóa sạch `HocSinh` và `KetQuaThi`.

### 2. Core API Layer (FastAPI)
- **Responsibility:** Chỉ tiếp nhận HTTP Request, gọi logic từ Service Layer và trả về Response theo đúng Pydantic Schema. Tuyệt đối không nhồi nhét logic xử lý chuỗi hoặc tính toán điểm số trực tiếp trong file Route.
- **Validation:** 100% dữ liệu đầu vào (Payload) và đầu ra (Response) phải được kiểm tra qua Pydantic v2.

### 3. AI Service Module (Gemini API)
- **Isolation:** Toàn bộ logic giao tiếp với LLM phải được cô lập tại `backend/app/services/gemini_service.py`.
- **I/O Format:** Đầu vào là String (văn bản thô). Đầu ra bắt buộc phải được LLM ép về định dạng **JSON Array** khớp chính xác với các trường dữ liệu của bảng `CauHoi` (Nội dung, A, B, C, D, Đáp án đúng).

### 4. Real-time Module (Socket.io)
- **Responsibility:** Phát sóng (Broadcast) trạng thái đếm ngược thời gian, trạng thái phòng thi (`DANG_CHO`, `DANG_THI`, `DA_DONG`) và ghi nhận học sinh kết nối.
- **Constraint:** KHÔNG gọi các truy vấn Database quét diện rộng (Select All) bên trong các event loop của Socket để tránh nghẽn luồng.

## II. COMMUNICATION PROTOCOLS

- **Frontend ↔ Backend (REST):** Giao tiếp qua HTTP cho mọi tác vụ CRUD tĩnh (Đăng ký, Đăng nhập bằng JWT Token, Khởi tạo Đề thi, Quản lý kho câu hỏi).
- **Frontend ↔ Backend (WebSocket):** Giao tiếp hai chiều độc quyền cho phiên thi trực tiếp. Chuyển giao ngay lập tức khi học sinh nhập mã Code vào phòng.
- **Router ↔ Database:** Lớp Router giao tiếp với Session của PostgreSQL thông qua cơ chế Dependency Injection (`Depends(get_db)` của FastAPI).

## III. ERROR HANDLING & STATE RECOVERY

Mọi ngoại lệ (Exceptions) xảy ra phải kích hoạt cơ chế tự động đưa hệ thống về trạng thái an toàn sau đây:

- **ERR_01 (Gemini API Timeout/Fail):** Kích hoạt nếu quá trình gọi AI sinh câu hỏi mất quá 15 giây hoặc trả về JSON lỗi.
  - *Hành động:* Hủy transaction cơ sở dữ liệu hiện tại (DB Rollback).
  - *State:* Trả về HTTP 503 (Service Unavailable) hoặc 400 (Bad Request). KHÔNG lưu bản ghi `DeThi` trống vào hệ thống.
- **ERR_02 (Học sinh ngắt kết nối đột ngột):** Phát hiện qua sự kiện `disconnect` của Socket.io.
  - *Hành động:* Bắt ID học sinh bị văng khỏi luồng.
  - *State:* Update tức thì bảng `KetQuaThi`, set `trang_thai = 'MAT_KET_NOI'`. Lưu vết mốc thời gian để đóng băng đồng hồ đếm ngược của học sinh đó.
- **ERR_03 (Lỗi Validation Dữ liệu Khuyết thiếu):** Xảy ra khi Frontend gửi thiếu trường (vd: thiếu `dap_an_d`).
  - *Hành động:* Pydantic tự động chặn lại trước khi chạm tới Controller.
  - *State:* Trả về HTTP 422 (Unprocessable Entity) kèm chi tiết lỗi. Block hoàn toàn truy vấn DB.

## IV. DEFINITION OF DONE (PROOF OF COMPLETION)

Agent không được tuyên bố hoàn thành task nếu chưa xuất ra được các bằng chứng kiểm toán (Audit Proofs) sau:

1. **Schema Verification Proof:** Mã nguồn API tạo mới phải đi kèm file Pydantic Schema. Các trường trong Schema phải khớp 100% với kiểu dữ liệu của `models.py` (Ví dụ: `thoi_gian_lam_bai` phải là số nguyên `int`, không được là `String`).
2. **State Output Proof:** Khi lập trình xong một API chuyển đổi trạng thái (Ví dụ: Bắt đầu làm bài), Agent phải in ra một JSON response mẫu chứng minh trường `trang_thai_phong` đã được cập nhật thành công từ `DANG_CHO` sang `DANG_THI`.
3. **Transaction Safety Proof:** Đối với API chứa từ 2 thao tác INSERT/UPDATE trở lên (Ví dụ: Tạo 1 Đề thi + Insert 20 Câu hỏi cùng lúc), Agent phải chỉ rõ khối mã `try-except` và lệnh `db.rollback()` chứng minh tính an toàn nếu tiến trình gãy đổ giữa chừng.
